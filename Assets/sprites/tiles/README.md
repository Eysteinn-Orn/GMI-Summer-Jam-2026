# Custom Tiles

Drop 16x16 PNGs into this folder. The Custom Tiles editor plugin will
automatically register each one as a TileSetAtlasSource in
`res://Assets/tilesets/graveyard.tres`, so it shows up in the TileMap editor.

Anything that isn't 16x16 is reported in the Output panel and skipped.
Delete a PNG to drop the matching atlas source.
